# tono. story maker

`tono.` は、写真を読み込んで Instagram Stories などに使える縦長ビジュアルを作るための、ミニマルなストーリー画像エディタです。

ブラウザだけで動作する静的アプリで、写真の配置、背景色、テキスト、レイアウトを調整し、PNGとして書き出せます。

## 主な機能

- 写真の読み込みと差し替え
- 写真のズーム、位置調整、軸固定ドラッグ
- 写真の角度調整
- 背景色の選択
- 写真から抽出したカラーパレット候補
- テキスト編集
  - 日付 / タグ
  - メインキャプション
  - サブテキスト
- テキストの表示 / 非表示
- 複数のカードレイアウト
  - 基本レイアウト
  - 丸形レイアウト
  - 不定形 organic レイアウト
  - パレット / selvedge 系レイアウト
  - 横長・縦長写真向けレイアウト
- PNG書き出し
- PWA用 manifest / service worker

## 使い方

1. `index.html` をブラウザで開きます。
2. `Photo` タブの `choose photo` から写真を選びます。
3. 必要に応じて背景色、写真位置、ズーム、角度を調整します。
4. `Layout` タブでカードの見た目を選びます。
5. `Text` タブで表示テキストを編集します。
6. `Export PNG` で画像を書き出します。

## 写真調整

`Position & Zoom` では、写真の切り抜き方を調整できます。

- `width`: 写真の横幅が枠に届くようにズームし、中央に戻します。
- `height`: 写真の縦幅が枠に届くようにズームし、中央に戻します。
- `free`: 写真を自由にドラッグできます。
- `x only`: 横方向だけドラッグできます。
- `y only`: 縦方向だけドラッグできます。
- `rotate`: 写真だけを傾けます。

不定形レイアウトではフレームだけが傾き、写真は通常は水平に見えるよう補正されています。写真自体を傾けたい場合は `rotate` を使います。

## 背景色

初期背景は白です。

写真を読み込むと写真由来のカラーパレット候補が表示されますが、背景色は自動変更されません。必要な色をユーザーが選びます。

## 書き出し

`Export PNG` は、編集画面のカード全体を基準に書き出します。

写真部分は `html2canvas` の `object-fit` 解釈差を避けるため、書き出し時だけ高解像度の内部 canvas に描画してからカード全体をPNG化します。これにより、編集画面と書き出し結果の写真トリミング差を抑えています。

## ファイル構成

```text
.
├─ index.html      # アプリ本体
├─ manifest.json   # PWA manifest
├─ sw.js           # service worker

```

## 開発メモ

ローカル確認は、静的サーバーで開くのが安全です。

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

その後、ブラウザで次を開きます。

```text
http://127.0.0.1:4173/index.html
```
